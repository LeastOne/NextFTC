# 3drdQuanomous

Reusable Quanomous program decoding, storage, and compilation for 3D Robotics
Duluth teams.

The library deliberately has no dependency on `3drdNextFTC`. It compiles stored
steps into generic values; each robot project decides how those values compose
into its command framework.

See the canonical [Quanomous architecture](../docs/architecture/quanomous.md),
[reusable platform requirements](../docs/requirements/platform.md), and
[phase-2 reconstruction guide](../docs/rebuild/phase-2.md) for the module contract
and design rationale.
